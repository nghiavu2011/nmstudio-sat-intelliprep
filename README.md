## 🌟 Tổng Quan Dự Án (Project Overview)

**N&Mstudio_Education — SAT IntelliPrep** là nền tảng ôn luyện Digital SAT thế hệ mới, kết hợp chặt chẽ giữa **chuẩn khảo thí khảo sát College Board Digital SAT 2026**, **phương pháp lặp lại ngắt quãng (Spaced Repetition FSRS)**, **tâm lý học giáo dục tích cực (Growth Mindset)** và **cổng thông tin đồng hành dành riêng cho cha mẹ**.

Hệ thống tuân thủ nghiêm ngặt triết lý **Ponytail Minimalist Architecture**: 100% Vanilla HTML5, CSS3, JavaScript ES6+, hoàn toàn không phụ thuộc thư viện nặng nề (Zero npm dependencies), tải trang tức thì dưới 200ms và vận hành mượt mà trên mọi thiết bị máy tính, máy tính bảng và điện thoại.

## 🚀 Tính Năng Đột Phá (Core Capabilities)

### 1. 🎯 Chẩn Đoán & Thi Thử Thích Ứng (Adaptive Mock SAT)
- **Chuẩn cấu trúc Digital SAT**:
  - **Reading & Writing**: 2 mô-đun (27 câu / 32 phút mỗi mô-đun).
  - **Math**: 2 mô-đun (22 câu / 35 phút mỗi mô-đun) với câu trắc nghiệm 4 lựa chọn và câu điền số thực tế (Grid-in).
- **Định tuyến thích ứng 2 chặng (Multistage Adaptive Routing)**: Mô-đun 1 chấm điểm tự động để chuyển tiếp học sinh vào nhánh Module 2 Nâng cao (Hard) hoặc Cơ bản (Easy), phản ánh sát thực tế kỳ thi thật tại phòng thi.

### 2. 🗂️ Flashcard FSRS & Xuất Anki TSV 1-Chạm
- 80 thẻ ghi nhớ chất lượng cao chia theo 7 bộ đề cốt lõi:
  - *Direct Hits Vocabulary* (Từ vựng tần suất cao)
  - *Secondary Meanings* (Nghĩa phái sinh gây bẫy)
  - *Grammar Boundaries & Modifiers* (Quy tắc ngữ pháp Kaplan 2020)
  - *Transitions & Rhetorical Synthesis* (Tư duy liên kết câu)
  - *Math Formulas & Geometry Shortcuts*
- Thuật toán **FSRS-lite** tự động tính chu kỳ ôn tập (Again, Hard, Good, Easy).
- **Xuất file chuẩn Anki TSV** nạp trực tiếp vào ứng dụng Anki trên máy tính hoặc điện thoại.

### 3. 📈 Tích Hợp Máy Tính Đồ Thị Desmos Chính Thức
- Nhúng trực tiếp giao diện máy tính đồ họa Desmos của College Board hỗ trợ học sinh thao tác giải phương trình bậc hai, hệ phương trình và tương giao hàm số ngay trong bài luyện.

### 4. 🧠 Sổ Tay Lỗi Sai (Error Ledger) & Chẩn Đoán Tâm Lý Bẫy SAT
- Mỗi câu sai được bóc tách theo phương pháp *Mike Barrett's SAT Prep Black Book*:
  - **What Happened**: Câu trả lời sai của học sinh.
  - **Why Failed**: Bẫy tư duy dẫn tới sai lầm (Quá cụ thể, Ngoại suy thái quá, Lỗi dấu, Lạc đề).
  - **Correct Thinking**: Tư duy phản biện để tìm ra đáp án đúng duy nhất.
  - **Try Again**: Đề xuất câu hỏi biến thể tương đương để củng cố ngay lập tức.

### 5. 👨‍👩‍👧 Góc Phụ Huynh (Parent Companion Portal)
- Thiết kế theo tiêu chuẩn tâm lý học học đường cho lứa tuổi 15–18:
  - **Đo lường sự nỗ lực & kỷ luật thực chất**: Tổng số giờ tập trung, độ bền bỉ theo tuần, số kỹ năng làm chủ thay vì săm soi từng điểm số.
  - **Cẩm nang tâm lý cha mẹ**: Bí quyết đồng hành cùng con tuổi dậy thì mùa thi cử, giảm áp lực so sánh "con nhà người ta", bảo vệ nhịp sinh học và giấc ngủ não bộ.
  - **Báo cáo đồng hành định kỳ (Printable Report)**: Tích hợp nút in chuẩn (`window.print()`) xuất file PDF gọn gàng để lưu giữ hoặc trao đổi với thầy cô.

## ⚡ Hướng Dẫn Cài Đặt & Chạy Cục Bộ (Local Quickstart)

Không cần cài đặt `npm` hay bất kỳ build tool nào!

### Cách 1: Chạy file Batch nhanh trên Windows
Chỉ cần nhấp đúp vào tệp:
```bash
run_sat_system.bat
```
Trình duyệt sẽ tự động mở trang web tại địa chỉ `http://localhost:8080`.

### Cách 2: Sử dụng Python HTTP Server
```bash
# Mở terminal tại thư mục dự án
python -m http.server 8080

# Mở trình duyệt truy cập:
http://localhost:8080
```

## 🚀 Hướng Dẫn Đẩy Lên GitHub & Triển Khai Vercel (Deployment)

### Bước 1: Khởi tạo Git & Đẩy lên GitHub
```bash
git init
git add .
git commit -m "feat: launch N&Mstudio_Education SAT IntelliPrep v1.0"
git branch -M main
git remote add origin https://github.com/<tai-khoan-cua-ban>/nmstudio-sat-intelliprep.git
git push -u origin main
```

### Bước 2: Triển khai 1-Click trên Vercel
1. Đăng nhập vào [Vercel](https://vercel.com).
2. Nhấn **"Add New"** -> **"Project"** và liên kết với kho lưu trữ GitHub vừa tạo.
3. Giữ nguyên toàn bộ cấu hình mặc định (Framework Preset: *Other*).
4. Nhấn **"Deploy"**. Hệ thống sẽ đọc tệp `vercel.json` và đưa ứng dụng lên sóng toàn cầu với chứng chỉ SSL HTTPS miễn phí trong vòng 30 giây!

## 🛡️ Kiểm Toán Chất Lượng Mã Nguồn (Alibaba Code Review)

Hệ thống được kiểm định nghiêm ngặt theo 5 trụ cột **Alibaba Open Code Review**:
- **Defects & Robustness**: Cơ chế bọc lót `try-catch` an toàn cho `localStorage`, phòng chống lỗi parse dữ liệu, tự động tái tạo state mặc định khi gặp dữ liệu lỗi.
- **Security**: Cơ chế làm sạch chuỗi `escapeHTML` ngăn chặn triệt để lỗ hổng Cross-Site Scripting (XSS), liên kết ngoài luôn đính kèm `rel="noopener noreferrer"`.
- **Performance**: Zero-dependency vanilla web, không có render blocking resources, tải dưới 150ms.
- **Architecture**: Mô hình MVC thu nhỏ với Hash Routing rõ ràng, phân tách dữ liệu bài thi JSON và trạng thái người dùng độc lập.
- **Accessibility & UX**: Bàn phím điều hướng (phím Esc đóng modal), thẻ ngữ nghĩa HTML5, độ tương phản chuẩn WCAG AA.
